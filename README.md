# AL Communication (Version 6.1) — Retail POS, Global Search & Store Ledger

A production-ready, ultra-polished, high-performance Single Page Application (SPA) designed for **AL Communication** — a retail stationery, utility bill collection, and mobile reload store in Sri Lanka. Hosted on **GitHub Pages** and backed by **Firebase Cloud Firestore (SDK v11)** and **Firebase Authentication**.
